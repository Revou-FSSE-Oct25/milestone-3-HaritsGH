# RevoShop

This is an e-commerce app for my practice and assignment. You can visit the app here: https://milestone-3-haritsgh.vercel.app

## Overview

An e-commerce app created with *React* and *Next.js*. This app consists only a home page and product detail pages for each item.
You can see all the items in the home page. You can visit the product detail page by clicking the blue button that says `Details`.
You need to log in as a User or an Admin to add items to your cart.
The items are fetched from [Platzi's FakeStoreAPI](https://fakeapi.platzi.com/).

## Features

1. Item showcase with product cards.
2. A product detail page for each item that displays one product image, it's title, price, and description.
3. Responsive UI design dependent of your screen width.
4. Non-functioning `Checkout` button in Cart page.

## Technologies Used

1. Javascript
2. React
3. Next.js
4. TailwindCSS
